# Export-safe raw-load allowlist.
# Format:
# kind|file|line substring|target classification|why this is safe
# Keep this file small. Prefer ResourceLoader/load() for imported assets and
# export_presets.cfg include_filter coverage for genuine raw data.
raw-data|systems/render/terrain_visual_builder.gd|FileAccess.get_file_as_bytes(tile_data.heightmap_path)|res://data/regions/**/heightmap.bin|Zion render tiles read raw heightmap.bin data; export_presets.cfg includes data/regions/*, and the reader asserts the exact byte count before use.
raw-data|systems/render/terrain_visual_builder.gd|FileAccess.open(path, FileAccess.READ)|res://data/regions/**/{collision_tiles_manifest.json,tile.json}|TerrainVisualBuilder._load_json_dictionary is only used for region manifests/tile sidecars in data/regions, which are raw JSON data covered by export_presets.cfg include_filter.
imported-fallback|systems/render/terrain_visual_builder.gd|image.load(path)|res://*.png, res://*.jpg imported texture sources|TerrainVisualBuilder._load_source_image can load imported Texture2D pixels first and falls back to _image_from_imported_texture after raw Image.load fails, so exports do not depend on stripped raw texture files.
raw-data|systems/world/tile_streamer.gd|FileAccess.open(sidecar_path, FileAccess.READ)|res://data/regions/**/tile.json|TileStreamer collision sidecars are raw JSON data under data/regions, covered by export_presets.cfg include_filter.
raw-data|systems/world/tile_streamer.gd|FileAccess.get_file_as_bytes(heightmap_path)|res://data/regions/**/heightmap.bin|TileStreamer collision heightmaps are raw .bin data under data/regions, covered by export_presets.cfg include_filter, and byte-count checked against tile.json before use.
raw-data|systems/world/tile_streamer.gd|FileAccess.open(manifest_path, FileAccess.READ)|res://data/regions/**/collision_tiles_manifest.json|TileStreamer manifests are raw JSON data under data/regions, covered by export_presets.cfg include_filter.
raw-data|systems/world/surface_map.gd|FileAccess.open(path, FileAccess.READ)|res://data/terrain/*surface_id.png|The runtime surface sampler reads raw data/terrain/*surface_id.png bytes when packed that way; if export strips the source and mounts an imported texture, SurfaceMap falls back to Texture2D.get_image() first-channel samples. export_presets.cfg includes data/terrain/* and .gitignore blocks accidental .import sidecars for these data maps.
